## Field Icons from Schema Metadata

Schema metadata can drive application-owned presentation such as field icons without changing Filter Sphere's public APIs. This standalone MUI recipe overrides only `templates.FieldSelect`; see [Using Schema Metadata](/fn-sphere/guides/best-practices/#using-schema-metadata) for the framework-neutral data flow.
