The Filter Sphere skill guides AI coding agents through integration choices and the relevant documentation.

## Skills

The skill includes a React filtering example, extension guidelines, and links to filtering and sorting guides.

### Installation

Install the Filter Sphere skill to your AI coding agent:

```bash
npx skills add lawvs/fn-sphere
```

The [skill source](https://github.com/lawvs/fn-sphere/tree/main/skills/filter-sphere) is part of this repository. The root `AGENTS.md` directs agents to read it for Filter Sphere integrations, themes, localization, and examples.

Within this repository, the skill points agents to local documentation. In other projects, it directs them to the published guides and installed package types.

### Example Prompts

Once installed, you can ask agents to help with various Filter Sphere tasks:

```
Add a filter UI to my data table using Filter Sphere
```

```
Create a custom filter function that checks if a string matches a regex pattern for use in Filter Sphere
```

```
Add localization support to my filter builder with English and Chinese in Filter Sphere
```

### What's Included

The skill contains:

- A React setup with `useFilterSphere`, `FilterSphereProvider`, `FilterBuilder`, and filtered results.
- Guidance on schema defaults, theme layers, template composition, and translation lookup.
- Reading paths for custom functions, parameter inputs, metadata, persistence, sorting, and examples.

Detailed API behavior stays in the linked guides. The skill helps agents choose which guide and extension point apply to the task.
