Use the Filter Sphere skill to help an AI coding agent integrate filtering and sorting into your application or library.

## Skills

The skill covers package selection, rule state ownership, theme extension points, and translation integration. It also includes a React filtering example and links to detailed guides.

### Installation

Install the Filter Sphere skill to your AI coding agent:

```bash
npx skills add lawvs/fn-sphere
```

The installed skill works in your project without a checkout of fn-sphere. It directs agents to published guides and the types in your installed packages.

The [skill source](https://github.com/lawvs/fn-sphere/tree/main/skills/filter-sphere) is part of this repository. For repository contributors, `AGENTS.md` adds local documentation paths and example conventions.

### Example Prompts

Once installed, you can ask agents to help with various Filter Sphere tasks:

```
Add a filter UI to my data table using Filter Sphere
```

```
Create a custom filter function that checks if a string matches a regex pattern for use in Filter Sphere
```

```
Add localization support to my filter builder with English and Chinese in Filter Sphere
```

### What's Included

The skill contains:

- A React setup with `useFilterSphere`, `FilterSphereProvider`, `FilterBuilder`, and filtered results.
- Guidance on package selection, rule state ownership, reusable components, schema defaults, theme layers, and translation lookup.
- Reading paths for custom functions, parameter inputs, metadata, persistence, sorting, and examples.

Detailed API behavior stays in the linked guides. The skill helps agents choose which guide and extension point apply to the task.
