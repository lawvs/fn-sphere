Build a flow directly on the canvas. Add arithmetic nodes, connect numbered handles, change the graph inputs, and select a function node to delete it. The live output is compiled from the output-reachable part of the graph.

The JSON panel shows the semantic `FlowSpec` produced by the editor. Canvas-only state such as node positions and selection is intentionally excluded, so the displayed value can be validated with `flowSpecSchema`, stored, and compiled without React Flow.
